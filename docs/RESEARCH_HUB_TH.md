# หน้าวิจัยและนวัตกรรมของ Bienvica

## ตำแหน่งและลิงก์สำหรับ QR

- หน้าเมนูหลัก: `https://bienvica.com/#/research`
- ลิงก์สั้นสำหรับ QR: `https://bienvica.com/research/shot`
- ลิงก์สั้นจะส่งต่อไปส่วนแนะนำช็อตในหน้าเดิม: `/#/research?section=shot`
- หลังนำโค้ดขึ้นเว็บแล้ว ให้ทดสอบลิงก์สั้นบนมือถือจริงก่อนพิมพ์ QR

หน้าเว็บเป็นข้อความ HTML ที่เลือกอ่านได้และปรับตามหน้าจอ ไม่ใช่ภาพยาวภาพเดียว กราฟเปิดดูขนาดเต็มได้ FAQ กดเปิด–ปิดได้ในหน้าเดียว

## เพิ่มงานวิจัยหรือคอนเทนต์ Facebook

1. เข้าสู่ระบบด้วยบัญชีผู้ดูแลเดิม
2. เปิดหลังบ้าน → **วิจัยและบทความ** (`/#/admin/research`)
3. กด **เพิ่มเนื้อหา** แล้วเลือกหมวด งานวิจัย / ความรู้และการพัฒนา / จาก Facebook
4. กรอกหัวข้อ วันที่ คำโปรย และเนื้อหา อัปโหลดภาพปกได้
5. ใส่ชื่อแหล่งอ้างอิงและลิงก์ต้นฉบับ ถ้าเป็นหมวด Facebook ต้องใช้ลิงก์ HTTPS ของ Facebook หรือ fb.watch
6. เลือก **บันทึกร่าง** เพื่อเก็บไว้ก่อน หรือ **เผยแพร่** เพื่อแสดงในคลังความรู้
7. กลับมาแก้ไขได้จากรายการเดิม ถ้าต้องการนำเรื่องลงชั่วคราว ให้เลือก **บันทึกเป็นร่างและซ่อนจากหน้าเว็บ**

คลังความรู้เรียงตามวันที่ของเนื้อหาจากใหม่ไปเก่า ค้นหาด้วยคำและกรองหมวดได้ โพสต์เหล่านี้ใช้ข้อมูล `posts` เดิม โดยแยกด้วย `placement: research` จึงไม่ต้องสร้างคอลเลกชันหรือเปิดสิทธิ์ Firestore เพิ่ม และไม่ปะปนกับกระทู้สมาชิก

ไม่ได้ดึง Facebook อัตโนมัติ ให้ทีมเลือกภาพ/สรุปและวางลิงก์ของโพสต์ที่ต้องการนำมารวบรวม ภาพอัปโหลดผ่าน Firebase Storage เดิม ต้องเป็นผู้ดูแลจึงบันทึกและเผยแพร่ได้

## เนื้อหาผลทดสอบช็อต

ข้อความอยู่ใน `web/src/research.js` และอ้างอิงค่าที่ผู้ใช้ยืนยันจาก PPT:
- เครื่องดื่มสำเร็จสูตรน้ำตาลต่ำ: DPPH IC50 30 µL/mL, ORAC 95 µmol TE/mL sample
- ตัวอย่าง ACV: ORAC 98 µmol TE/mL sample
- α-glucosidase: IC50 เบียงวิก้า 0.27%, ตัวอย่าง ACV 2.89%; อัตราส่วนประมาณ 10.7 เท่าเป็นอัตราส่วนความเข้มข้นในการทดลอง
- กราฟ Caco-2/2-NBDG: เบียงวิก้า 0.75%; ไม่ใช่กราฟน้ำตาลในเลือดคนและไม่ใช่อัตราผสมที่แนะนำให้ดื่ม
- อ้างอิงชื่อโครงการ RAINS for Semi-Industrial Food Valley (Functional food and Personalized food) ประจำปี 2568 สนับสนุนโดย สกว. ตามข้อความที่ผู้ใช้ยืนยัน

ไม่มีลิงก์รายงานฉบับเต็มหรือไฟล์ PPT ที่ยังไม่ตีพิมพ์ ไม่มีการเพิ่มรายการขายช็อต ราคา หรือปุ่มชำระเงินใหม่

กราฟเป็นภาพจากผลการทดลองที่ผู้ใช้ให้มา โดยทำพื้นหลังให้เรียบ ไม่ได้สร้างจุดข้อมูลใหม่ ภาพขวดและปิเปตเป็นภาพประกอบ

## ตรวจสอบและนำขึ้นเว็บ

งานนี้ต่อยอดจาก `codex/firebase-company-rebuild` ซึ่งมีเว็บ Netlify/Firebase รุ่นปัจจุบันในโฟลเดอร์ `web` ไม่ใช่โค้ด Manus เดิมบน `main` ของ repository

```sh
cd web
npm ci
npm test
npm run build
```

Netlify ต้อง build จากโฟลเดอร์ `web` พร้อมตัวแปร APP_MODE/Firebase เดิม ไม่ต้องเปลี่ยน Stripe, ERP, DNS หรือกฎสิทธิ์ การ build ในเครื่องตรวจสอบใช้โหมด demo; production ต้องใช้ค่าตั้งเดิมของ Netlify
